## 示例

### 问题编号：20260416-01

### 1. 问题现象

编译时报错：

```
stray '\377' in program
```

### 2. 发生环境

- 系统版本：Ubuntu 20.04
- 项目版本：控制器程序
- 编译环境：catkin_make
- 相关模块：high_voltage_controller

### 3. 问题原因

源文件编码格式异常，文件开头存在非法字符或 BOM/乱码内容。

### 4. 解决方法

重新用正常 UTF-8 格式保存源码文件，删除文件开头异常字符后重新编译。

### 5. 涉及文件

```
src/high_voltage_controller/src/high_voltage_controller_node.cpp
```

### 6. 后续注意事项

后续从 Windows 复制代码到 Linux 项目时，要注意文件编码，避免引入非法字符。
