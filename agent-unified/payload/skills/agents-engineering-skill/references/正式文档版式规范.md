# 正式文档版式规范

仅在创建或修改正式 Word 交付物时读取。本文件随工程技能安装，Windows 与 Linux 共用；用户指定格式或已有项目模板优先。普通问答、仓库文档和 Git 提交说明使用 Markdown。

## 页面与文字

- 页面为 A4 纵向；内容确需横向或用户另有要求时调整。
- 允许字体为宋体、黑体、楷体和 Times New Roman。中文正文宋体、标题黑体、图表题楷体；英文、英文缩写、数字及西文字符 Times New Roman。
- 文档标题及各级标题四号 14 磅；正文小四号 12 磅；图表题五号 10.5 磅；表头黑体五号优先，表格正文中文宋体、英文 Times New Roman，五号优先。
- 所有段落段前、段后 0；标题与正文 1.5 倍行距；图表题及表格内部单倍行距，不混用固定值或其他行距。标题层级清晰，避免标题孤立于页底，目录按篇幅与查阅需要添加。
- Windows 和 Linux 都先核实所需字体真实可用；不得静默替换字体后宣称符合规范。字体缺失时指出具体缺项及受影响检查，使用已授权、具有合法来源的字体或符合条件的渲染环境完成交付。

## 表格、图片与内容组织

- 表格用于可比较的行列数据，不包装普通段落或作为装饰。列宽、对齐、疏密清晰，数值、单位和小数位统一；合并单元格、分组表头和备注按需使用。
- 表题在表格上方居中，格式“表1 ××××”；跨页重复表头，尽量避免表题与表格分离。
- 图示只在显著提升理解时使用，保持清晰、简洁、比例正确，无拉伸或信息堆叠。图题在图片下方居中，格式“图1 ××××”。
- 正式文档图片内中文宋体，英文 Times New Roman；正常比例下可直接阅读。数据图标明坐标轴、单位、图例及必要来源，不为“图文并茂”强行插图。
- 内容结构按问题选最轻有效形式；问题分析可采用现象、证据、原因、影响、建议、验证的顺序，不机械套模板。结论对应证据，建议具体、可执行、可验证，说明前置条件及风险。

## 交付检查

- 执行结构检查与逐页渲染检查；修复截断、重叠、错页、字体替换、表格破损及图片失真后，只复核受影响页面及必要关联版式。
- 核对 A4、字体白名单、字号、段前段后、行距、标题层级、分页及页码；核对图表题位置、跨页表头、图表清晰度与风格。
- 核对事实、推断标记、来源、查询日期、关键数字和链接，去除虚构、夸大、敏感信息、占位符、无关装饰和模板残留。
- 以最终逐页渲染结果为准；未完成渲染检查不能声称排版已验证。聊天仅给结论、文件链接、验证状态与必要限制。
