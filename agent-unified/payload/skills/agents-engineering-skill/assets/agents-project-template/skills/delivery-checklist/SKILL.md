# 交付检查清单

## 使用已有证据

对照用户目标与本次实际改动，汇总此前已完成的检查。相关输入和环境未变时复用可追溯结果；不要为填写交付模板重新运行测试。发现影响验收的证据缺口时，只补充缺失的相关检查，完成后停止。

标准或高风险任务按需核对项目根 `references/definition-of-done.md` 的适用项；已读取且未变化时不重复加载。不适用项不要求新增测试或文档。

## 组织交付

简单修改用短段落说明结果、关键文件与验证状态即可。复杂交付按需使用项目根 `references/delivery-format.md`，保留有助于判断结果的信息：

- 完成结果和关键改动。
- 实际验证命令/操作、环境、结果；注明复用的证据及其覆盖范围。
- 影响验收的失败、未完成或未验证项。
- 重要风险、兼容影响及必要的回退方法。

只有发现有复用价值且已定位的真实问题才更新项目问题记录；普通任务不要求创建记录或填“无更新”。正式格式遵循用户要求，不能把参考模板所有栏目当成每次必填项。

## 停止条件

范围已交代、必要证据有效、剩余限制明确后直接交付，不再启动构建、全仓扫描、专项审查或测试。
