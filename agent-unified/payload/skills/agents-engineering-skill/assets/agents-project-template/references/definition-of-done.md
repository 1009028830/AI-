# Definition of Done

这是所有修改共享的完成底线；单个任务的验收标准在此基础上增加，不替代本清单。

## 范围与正确性

- [ ] 实现与用户目标和已确认方案一致。
- [ ] 未混入无关重构、未确认功能或意外生成文件。
- [ ] 已检查目标文件适用的全部 AGENTS 规则。
- [ ] 用户已有改动未被覆盖或回退。

## 质量与安全

- [ ] 错误路径、边界输入和资源释放与风险相匹配。
- [ ] 外部输入、配置、协议、文件和网络数据经过必要校验。
- [ ] 未泄露密钥、Token、密码、个人数据或敏感路径。
- [ ] 新依赖、公共接口、数据格式和兼容性变化已明确说明并获授权。

## 验证证据

- [ ] 已运行最小相关测试、静态检查或构建。
- [ ] L2/L3 修改已执行适当回归检查。
- [ ] 验证记录包含命令/操作、环境、预期、实际和结论。
- [ ] 无法验证的目标环境、硬件或生产行为已明确标注。
- [ ] 没有使用“应该可以”“看起来正常”代替证据。

## 文档与交付

- [ ] 行为、接口、配置或运行方式变化已更新权威文档。
- [ ] 新发现且已定位的问题已更新 `docs/development_memory.md`，或明确说明无更新。
- [ ] 交付列出修改文件、完成内容、未做内容、验证结果、风险与回退方法。
- [ ] AGENTS/skills/references 变更已通过 AGENTS 验证器。
