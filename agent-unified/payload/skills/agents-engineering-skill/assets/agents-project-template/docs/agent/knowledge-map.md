# Agent knowledge map

本文件是 Agent 查找项目事实的导航表。只登记权威来源，不复制正文。复制模板后按项目实际情况填写或删除无关条目。

## 项目事实

| 主题 | 权威来源 | 状态 / 验证边界 |
|---|---|---|
| 产品目标与验收 | `README.md` 或产品规格 | TODO |
| 架构与模块边界 | `docs/architecture.md` 或源码入口 | TODO |
| 构建与依赖 | 构建清单、锁文件、CI | TODO |
| 测试与质量门禁 | 测试配置、CI、`references/definition-of-done.md` | TODO |

## 按任务加载

| 当前任务 | 优先读取 |
|---|---|
| 新功能 / 重构 | 需求或规格、相关模块入口、现有测试、历史问题 |
| Bug 修复 | 复现证据、相关实现与调用方、测试、历史问题 |
| UI 修改 | 页面/组件、设计约束、状态与错误态、视觉验证入口 |
| API / 协议 | 正式接口或协议、兼容性约束、边界测试 |
| 配置 / 部署 | 配置 schema、示例配置、启动脚本、回退步骤 |
| 性能 | 基线数据、分析工具、目标阈值、对比方法 |

## 维护

- 新增长期文档时在此登记。
- 文档与代码冲突时记录冲突，验证后修正权威来源。
- 易过期条目标注负责人、版本或最后验证日期。
- 不把临时对话、未确认方案或猜测登记为事实。
