# 电池与 BMS 工程检查项

版本 1.0.0；编写/来源查询日期：2026-10-16。以下 B 编号为原创工程检查项，不是标准条款编号或其全文替代。使用 [规范目录](standards.md) 确定车用、储能、充电或运输适用范围。

## 系统、采样与 AFE

- **B01 电池边界**：明确化学体系、容量、串并联、电芯/模组/包/簇层级、应用场景、寿命及可用能量定义；不能直接复用另一电芯的 OCV 曲线和充电限值。
- **B02 参数管理**：每个限值记录来源、单位、符号、公差、温度/老化/工况、保护等级、去抖、恢复与版本；区分产品规格、标定参数和法规要求。
- **B03 信号有效性**：电压、电流、温度、绝缘与反馈携带时间和有效状态；上电未就绪、超时、越界、饱和、卡滞和通信失败分别处理，不把无效值变成正常 0。
- **B04 AFE 初始化**：核对实际芯片/硅版本、供电、唤醒、地址分配、通道映射、基准与转换模式；按器件手册读回关键配置和自检结果，处理部分器件未初始化。
- **B05 链路完整性**：CRC/PEC、序号/地址、长度、超时和菊花链断点检测遵循所用器件协议；限定重试，完整帧验证前不能发布控制用样本。
- **B06 校准与误差**：评估 ADC、基准、分压、隔离、电流传感器零偏、增益、温漂和量化误差；校准数据绑定硬件与版本，损坏/缺失有可验证处理。
- **B07 同步与带宽**：确认电流和电压采样时差、转换/滤波延迟及采样率；瞬态功率/内阻计算不混用不同时间窗样本，保护预算计入滤波延迟。
- **B08 故障诊断**：识别开线、短线、传感器卡滞、通道映射错、包压与单体和不一致；诊断注入/测量本身对采样、均衡和控制的影响应隔离或标记。
- **B09 独立监控**：按安全架构检查软件监控、AFE 硬件保护、独立比较/监测链和供电失效行为，不能把两段读取同一错误数据的软件称为独立冗余。

## SOC、SOH、SOP 与数据持久化

- **B10 电流积分**：固定充放电符号、时间单位和容量单位；使用实际时间间隔处理丢样、睡眠和计时回绕，测试零偏累积、积分溢出及容量变化。
- **B11 SOC 初始化**：说明上电恢复、静置条件、OCV 校正、温度和迟滞假设；负载下端电压不能无条件当 OCV，异常跳变不得被显示平滑掩盖。
- **B12 SOC 估计边界**：验证低温、老化、平台区、动态工况、单体不一致和极端 SOC；保留误差/可信度与失效标志，不将 SOC 精确显示误作实际精度。
- **B13 SOH 定义**：区分容量保持率、功率能力和内阻增长；估计需温度/工况归一化、参考测量及可观测条件，不能只用循环次数推定健康度。
- **B14 SOP 限值**：给出充/放电方向、持续与脉冲时间窗；合并电芯电压、电流、温度、SOC、SOH、冷却和接触器等约束，动态限值含有效期和变化率。
- **B15 异常降级**：估算不可信时采用项目定义的保守能力或禁止条件；电芯过压/欠压等直接保护不依赖 SOC 模型是否“正常”。
- **B16 非易失数据**：SOC/SOH、累计量、故障与标定考虑写入寿命、掉电、双份/事务策略、校验和兼容迁移；测试断电后的恢复可信度和计数不倒退策略。

## 均衡与热管理

- **B17 均衡准入**：依据电芯电压差、SOC、温度、测量有效性和工作状态定义准入/退出；不能只因电压偏高持续开启均衡。
- **B18 均衡执行**：核对通道互斥、最大同时通道、电阻功耗、AFE 热限制及定时；检查测量受均衡影响、通信中断/复位后的默认状态与硬件超时。
- **B19 热状态**：区分电芯、母排、连接器、功率器件和冷却介质温度；评估传感器位置、滞后、梯度和失效，最高测点温度不必然等于电芯最高温度。
- **B20 热执行器**：泵、风扇、阀和加热器有允许工况、供电/通信前提、反馈和故障处理；请求值不能当成实际流量或热量。
- **B21 低温与降额**：充电、放电、加热和预热转换遵循电芯/系统限制；动态降额有迟滞和恢复条件，不以延迟保护维持功率。
- **B22 热事件**：结合项目定义的温度、温升率、气体/压力等传感证据区分预警和故障；通信/日志/低压供电可用性纳入响应设计，禁止声称软件可阻止所有热失控。

## 高压状态机与保护

- **B23 状态机**：定义上电自检、待机、预充、运行、充电、故障、关机和休眠等实际状态；转换包含准入、退出、优先级、超时和执行器反馈，未定义事件有明确处理。
- **B24 预充**：依据实际电路确认母线/包压差、接触器反馈、电流与时间条件；验证电阻热容量、重复预充次数、负载未释放和测量失效，不采用统一固定预充时长。
- **B25 接触器诊断**：综合辅助触点和电压/电流确认吸合、拒动、粘连及线圈异常；接触器通断能力与实际负载一致，不能仅由控制输出推定物理状态。
- **B26 HVIL/绝缘**：核对高压互锁、绝缘监测适用电路及检测时机，区别故障与启动/测量未就绪；处理滤波、检测间隔和多个控制器的响应分工。
- **B27 故障优先级**：处理充电/放电、行驶/静止、故障并发与降级能力；安全响应来自危害分析和器件能力，不将“立刻断开”或“继续运行”作为通用策略。
- **B28 反应时间**：把采样、去抖、调度、通信、执行器动作及反馈串成端到端预算；保护定时不能在反复进入状态时被无意重置而无限延期。
- **B29 锁定与恢复**：明确自动恢复、维护解锁、上下电清除及不可清除故障；故障仍存在或反馈不可信时，诊断清码不直接恢复功率输出。
- **B30 失电与复位**：考虑控制器欠压、AFE 独立复位、通信中断、唤醒丢失和主从不同步；控制器重启不能凭旧状态直接闭合高压路径。

## 充电、通信与储能

- **B31 充电协议**：根据接口选择 GB/T、ISO 15118 或 OEM 规范，核对握手、阶段、单位、限值、超时与终止；旧协议消息不能未经映射直接用于新版实现。
- **B32 充电约束**：区分请求、充电机允许值和实际反馈；电流/电压约束与电芯保护协同，覆盖限值突变、停止后仍输出、连接器过温与通信中断。
- **B33 通信安全**：控制命令核对来源/权限、范围、序号、有效期和车辆/系统状态；遥测上传故障不能默认改变本地保护，远程命令不能绕过本地联锁。
- **B34 诊断与标定**：DTC、冻结帧、保护锁定、报警、清码分别管理；工程模式、充放电限值和出厂标定写入受控，更新参数前后验证依赖和完整性。
- **B35 储能层级**：明确 BMU/BCU/簇控、PCS、EMS 和消防系统职责及失联行为；簇并联、上下电和功率分配核对压差、环流、反馈与最弱单元约束。
- **B36 版本与现场**：电池更换、模组重组、校准更新和软件升级都评估参数/历史数据兼容；记录序列号、固件、标定和测试证据，现场数据脱敏后才用于复用。
