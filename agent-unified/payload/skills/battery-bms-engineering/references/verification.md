# BMS 分层验证矩阵

这是测试设计清单，不是危险试验操作规程。验收数值、工况和动作来自当前项目批准资料。

| 对象 | 建议覆盖的失败/边界 | 观测与判据 | 优先环境 |
| --- | --- | --- | --- |
| AFE/采样 | CRC/PEC 错误、断链、开线、超时、卡滞、映射错 | 有效标记、样本年龄、告警与降级；不误报正常值 | 单元、回放、信号模拟台架 |
| SOC | 电流符号、零偏、丢样、重启、容量变化、温度/老化 | 参考电量、误差、漂移、恢复条件；覆盖不同数据集 | 离线回放/SIL，后续电池台架 |
| SOH/SOP | 模型失配、温度变化、脉冲/持续窗口、低可信度 | 估计定义、限值方向、有效期、最弱单体约束 | 模型/回放、授权台架 |
| 保护链 | 阈值上下边界、去抖/迟滞、并发故障、任务超期 | 从故障发生到反应及反馈的总时间、优先级和恢复 | SIL/HIL，后续授权实物 |
| 预充/接触器 | 反馈不一致、粘连/拒动模型、母线异常、重复预充 | 准入、超时、锁定、禁止错误重试 | HIL/低能量模拟；实物另行授权 |
| 均衡 | 温度超限、采样无效、通道冲突、复位 | 允许通道、占空/时限、停止反馈、测量影响 | 单元、AFE 开发板与受控负载 |
| 热管理 | 温度传感故障、泵/阀无反馈、冷却不足模型 | 降额、报警、状态转换和恢复 | 模型/HIL，后续热台架 |
| 充电 | 阶段跳跃、超时、限值变化、停止不响应、断连 | 请求/应答/实际量对照、停机与联锁策略 | 协议仿真/HIL；实充另行授权 |
| 存储/升级 | 写入中掉电、校验坏、旧版本数据、部分 ECU 更新 | 恢复、一致性、可追溯和安全启动 | 主机故障模型、受控目标板 |
| 储能协同 | EMS/PCS 失联、单簇异常、并联请求冲突 | 本地保护独立性、功率约束、系统恢复 | 系统仿真/HIL；现场另行授权 |

每条结果包含需求/规则 ID、样本或模型版本、目标硬件与软件版本、输入条件、预期、实测、采样率/时间同步误差、证据位置和通过/失败/未执行/不适用。SOC/SOH 验证数据不能与拟合/标定数据混为同一独立验证集。

先证明逻辑与接口，再验证目标时序及仪器/硬件，最后按批准规程做实物验收。单元、模拟和 HIL 通过不能宣称通过 GB 38031、UN 38.3 或电芯热安全试验。
