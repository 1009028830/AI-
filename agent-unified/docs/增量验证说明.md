## 本仓库命令

从仓库根目录运行，Windows/Linux 按实际环境使用 `python`、`py -3` 或 `python3`：

```bash
python agent-unified/verify.py
python agent-unified/verify.py --run --only runner
python agent-unified/verify.py --run
python agent-unified/verify.py --run --force
```

默认集合为当前版本 `verification.json` 中启用的任务。首次执行建立基线；后续只执行声明输入变化的任务。公开版还包含公开安装器检查，个人完整包不包含公开安装器，因此配置中不添加该任务。

新项目使用工程技能初始化后，会获得 `scripts/verify.py` 和最小 `verification.json`。已有项目按需引入，默认不覆盖其规则和测试。已存在的旧项目不会被本次全局更新自动改写。

配置、状态和缓存边界见 [验证入口说明](../payload/skills/agents-engineering-skill/assets/agents-project-template/references/incremental-verification.md)。
