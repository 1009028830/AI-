## 如何用在项目中

- “使用 `$automotive-embedded-engineering`，根据本项目 DBC、UDS 规范和 RTOS 配置评审通信超时、休眠唤醒和升级恢复。”
- “使用 `$battery-bms-engineering`，检查 BMS 的采样有效性、SOC 积分、预充/接触器状态机和故障恢复，先做离线分析。”
- 现有 STM32、ESP-IDF、Linux 应用/驱动技能继续处理平台实现；这两个技能补充领域约束和工程证据。
- Windows/Linux 都恢复相同规则文本；仿真软件、目标编译器、CAN 后端和仪器按目标环境分别准备。

## 范围与验证限制

规范目录记录官方题录、公开摘要、版次和访问限制；没有把未读取的付费正文当作已审查条款。MISRA 部分页面、UN R100 正文访问受限，已逐项标明。项目采用前补齐合法正文、修改单及适用性分析。

规则不提供通用电压/温度/电流/时间定值，不指定默认 ASIL。参数依据电芯、硬件、安全分析和 OEM/系统要求；车用、储能、充电和运输的标准不互相替代。

安装与结构检查仅证明规则可以交付。编译、SIL/HIL、目标板、真实电池、EMC/环境及整车验收的证据范围分别记录；本次未执行真实车辆或电池操作。
