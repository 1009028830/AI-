本仓库的 MIT 许可只适用于维护者有权授权的自编写内容，不改变外部软件、
标准、插件或文档的许可。链接与版本锁记录不是再授权。

- 本目录仅内置本仓库维护的工程模板、工程工具箱指导、组件复用及七项嵌入式/车载/电池专项工作流。
- 车载与 BMS 的 A/B 编号为原创工程检查项，不是标准条款。ISO、IEC、SAE、MISRA、AUTOSAR、VDA、UNECE、国家标准及器件厂商资料仅登记题录与来源，不附受限正文，也不将链接等同于再分发或商业使用授权。
- 组件复用技能中的 GitHub 清单仅提供链接、元数据和选型说明，不附带候选库的源码或二进制。
- 其他个人技能仅在 [skill-catalog.json](config/skill-catalog.json) 登记。
  已登记的 Anthropic、Vercel 等来源保留原始仓库和提交信息；本次不再分发其正文或脚本。
- 运行时、npm/Python 包、原生工具由各自上游维护。版本和哈希见 `config/`、`locks/`；
  下载或制作离线包时须保留适用许可证、版权声明和源代码义务。
- ST、Arm、Espressif、Linux Kernel、POSIX、CERT、BARR 和 MISRA 等资料在规范索引中
  引用；本库的摘要不替代标准正文。未附付费标准全文或限制再分发的资料。
- Codex 内置插件和账号连接由客户端管理，不复制插件缓存、授权令牌或第三方服务账号。

公开版和个人迁移包的收录范围不同；目录中的“reference-only”表示仅有来源登记。
